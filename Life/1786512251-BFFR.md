#Usage
- this hook will let defer a UI render or update

#Syntax

import { useDeferredValue } from 'react'
`const [count, setCount] = useState(0)
const deferredCountValue = useDeferredValue(count)`

#RuleOfThumb
- useDeferredValue is best used when props comes from url params, props, 3rd party state
