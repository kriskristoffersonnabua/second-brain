# Neovim Cursive Italic Font Setup (WSL Ubuntu)

> Replicates the cursive italic style (as seen with **Operator Mono / Victor Mono**) in Neovim running inside WSL Ubuntu on Windows Terminal.

---

## Prerequisites

- Windows Terminal (latest)
- WSL Ubuntu
- Neovim with a Treesitter-compatible colorscheme

---

## Step 1 — Install Victor Mono (Windows Side)

1. Download from **https://rubjo.github.io/victor-mono**
2. Extract the ZIP and select all `.ttf` files
3. Right-click → **Install for all users**

> Victor Mono is free and has the closest cursive italic style to Operator Mono.

---

## Step 2 — Configure Windows Terminal

Open `settings.json` (via `Ctrl+,` → **Open JSON file**) and set the font under `profiles.defaults`:

```json
{
  "profiles": {
    "defaults": {
      "font": {
        "face": "Victor Mono",
        "size": 12
      }
    }
  }
}
```

---

## Step 3 — Fix Italics Support in WSL

WSL's default terminfo may not support italics. Run the following inside WSL:

```bash
# Create a terminfo entry with italic support
cat > /tmp/tmux-256color.terminfo << 'EOF'
tmux-256color|tmux with 256 colors,
  sitm=\E[3m, ritm=\E[23m,
  use=screen-256color,
EOF

tic -x /tmp/tmux-256color.terminfo
```

Then add this to your `~/.bashrc` or `~/.zshrc`:

```bash
export TERM=xterm-256color
```

Reload your shell:

```bash
source ~/.bashrc
```

---

## Step 4 — Configure Neovim

Edit `~/.config/nvim/init.lua` and add:

```lua
-- Enable true color
vim.opt.termguicolors = true

-- Apply italic highlight groups whenever colorscheme loads
vim.api.nvim_create_autocmd("ColorScheme", {
  pattern = "*",
  callback = function()
    -- Standard groups
    vim.api.nvim_set_hl(0, "Comment",             { italic = true, fg = "#6a9955" })
    vim.api.nvim_set_hl(0, "Keyword",             { italic = true })
    vim.api.nvim_set_hl(0, "Function",            { italic = true })
    vim.api.nvim_set_hl(0, "Type",                { italic = true })

    -- Treesitter groups
    vim.api.nvim_set_hl(0, "@keyword",            { italic = true })
    vim.api.nvim_set_hl(0, "@keyword.function",   { italic = true })
    vim.api.nvim_set_hl(0, "@variable.parameter", { italic = true })
    vim.api.nvim_set_hl(0, "@type",               { italic = true })
    vim.api.nvim_set_hl(0, "@function",           { italic = true })
  end,
})

-- Set your colorscheme (must come after the autocmd)
vim.cmd("colorscheme tokyonight") -- swap with your preferred theme
```

---

## Step 5 — Verify Italics Work

Run this in your WSL terminal:

```bash
echo -e "\e[3m this should be italic \e[0m"
```

- ✅ Text appears slanted → italics are working
- ❌ Text looks normal → check Windows Terminal font config or `TERM` variable

## Troubleshooting

| Problem | Fix |
|---|---|
| Font not showing in terminal | Re-install font as **all users**, restart Windows Terminal |
| Italics display as reverse/underline | `TERM` variable not set; add `export TERM=xterm-256color` to shell rc |
| Italics not applying in Neovim | Make sure `vim.opt.termguicolors = true` is set before the autocmd |
| Treesitter groups not working | Run `:TSInstall <language>` and confirm Treesitter is active |
